## Battle Mechanics

### Damage Formula

All Pokémon are treated as **level 50**. Damage is calculated as:

```
Base = floor((22 × MovePower × StatRatio) / 50) + 2
```

Where **StatRatio** is:
- Physical moves: User's Attack ÷ Target's Defense
- Special moves: User's Sp. Attack ÷ Target's Sp. Defense

The base damage is then multiplied by the following modifiers (each applied with a floor after multiplication):

1. **Critical Hit** — 1/24 chance of a 1.5× multiplier.
2. **Random Roll** — A random value between 0.85 and 1.00.
3. **STAB (Same-Type Attack Bonus)** — If the move's type matches either of the user's types, damage is multiplied by 1.5×.
4. **Type Effectiveness** — Checked against *both* of the target's types (multiplied together). This can result in 0× (immunity), 0.25×, 0.5×, 1×, 2×, or 4× multipliers depending on single/dual typing.

### Resting Mechanic

Some moves cause the user to "rest" (lose turns). After using Giga Impact, Hyper Beam, Outrage, Rock Wrecker, Prismatic Laser, Meteor Assault, or Rest, the user's `resting` counter is incremented. While resting > 0, the Pokémon cannot act. Rest sets the counter to 2; the recharge moves set it to 1.

### Healing Mechanic

- **Roost / Recover / Synthesis / Moonlight / Slack Off**: Heals 50% of max HP, capped at full HP.
- **Rest**: Fully heals HP but costs 2 turns.
- **Giga Drain / Drain Punch / Leech Life / Horn Leech**: Heals the user for 50% of the damage dealt, capped at full HP.

### Recoil Mechanic

Some high-power moves deal recoil damage to the user after attacking:
- **Flare Blitz / Brave Bird**: User takes 33% of the damage dealt as recoil.
- **Wild Charge**: User takes 25% of the damage dealt as recoil.
- Recoil damage cannot KO the user — they will always be left with at least 1 HP.

### Stat Drop Mechanic

Some moves lower the user's own stats after attacking:
- **Close Combat**: User's Defense and Special Defense drop by 50% of their base values.
- **Draco Meteor**: User's Special Attack drops by 100% of its base value.
